今天正式介绍一下我的第一个完整作品——**[柒嘿（Qihei）· 黑色打字猫](https://github.com/xiaowu-fox/qihei-typing-cat)**，一只会陪你打字、动鼠标的 Windows 桌面宠物。

它不是一张会动的贴图，而是一个能实时感知你操作、有自己状态和情绪的小程序：你敲键盘，它就抬起爪子敲对应按键；你点鼠标，它就跟着按一下；你放着音乐，它会晃头飘音符；你忙别的不理它，过一会儿它自己就裹上小被子睡着了。

## 它到底能做什么

### 同步打字，按真实键位敲

这是整个项目的起点。通过全局键盘监听，柒嘿知道你按下的是哪个键，然后控制它的爪子落到面前那把小键盘的**同一个键位**上，键帽还会从按键上飞出来。整套动作不是简单切换图片，而是有完整的抬爪、落爪、回弹弧线，配合身体起伏和耳朵抖动，连续打字时它甚至会逐渐变得烦躁。

### 鼠标、眼神和情绪

- 点击鼠标时，它会做出握鼠标、按压的动作；
- 一套视线系统会在「看键盘 / 看鼠标 / 四处乱看」之间切换，光标靠近时眼睛还会跟着你走；
- 慢眨眼、瞳孔随操作变圆变细、被拖动时瞪眼、刚睡醒时眼神迷蒙；
- 内置情绪状态：愉悦、愤怒、悲伤、恐惧、惊讶、平静，不同情绪对应不同的眼神和动作。

### 有自己的生活节奏

二十秒没有操作，它会自己趴下去睡觉，任意一次打字、摸头或拖动都会把它唤醒。平时它还会冷不丁冒出一句碎碎念，从猫生感悟到鸡汤哲学都有；右键可以摸头撸猫，也能直接把它拖到屏幕任意位置。

### 音乐律动、隐私保护和全屏避让

- 用 WASAPI 检测系统是否真的在播放声音（暂停、停止不会误触发），一旦有音乐，它会漂浮音符、自然摇头，猫耳内侧还会跟着节奏闪动；
- 检测到焦点在密码框时，它会主动戴上眼罩，不看你输入的内容；
- 运行游戏或看视频进入真正全屏时，它会自动隐藏，不打扰你；办公、聊天、浏览器全屏则不会躲。

### 外观几乎全部可定制

- 两款模型皮肤（柒嘿 / 呆猫），外加多套装扮；
- 毛色、眼睛、内耳都能用 HSL 滑杆实时调整，右键菜单做成了类似 Win11 快捷设置的九宫格；
- 小键盘有经典白、暗夜黑、RGB 幻彩、青柠四种皮肤，RGB 灯效会实时流动；
- 整体大小支持 70%～132% 无级缩放，位置和敲键动作会自动跟随。

## 技术上是怎么实现的

功能看着热闹，但我给自己定了一条硬规矩：**只用系统自带的东西，不引入任何第三方库。**

- **技术栈**：C# + WPF（.NET Framework 4.8），整个程序是一个约 8000 行的单文件 `Program.cs`，靠 `csc` 命令行直接编译，不依赖 Visual Studio 工程；
- **透明置顶窗口**：`WindowStyle.None` + `AllowsTransparency` + `Topmost`，让猫浮在所有窗口之上，且只显示模型本身；
- **全局键鼠监听**：用 `SetWindowsHookEx` 挂低级键盘钩子（`WH_KEYBOARD_LL`）和鼠标钩子（`WH_MOUSE_LL`），即使自身不在前台也能感知操作；
- **音乐检测**：通过 COM 互操作调用 WASAPI 的 `IAudioSessionControl2`，判断音频会话的真实播放状态；
- **动画与状态**：大量使用 WPF 的 `Storyboard`、`DoubleAnimation` 配合 `CubicEase` 等缓动函数，让动作有预备、有回弹而不是机械跳变；所有行为由一个状态机统一调度；
- **密码框识别**：结合当前焦点控件判断，并用 UI Automation 兜底浏览器和自绘输入框。

打包也一并走完了：自写安装器脚本，最终产出两个发行版本——

- **安装版（约 0.5 MB）**：带快捷方式、开机自启和完整卸载；
- **绿色版（约 0.2 MB）**：解压即用，不写注册表。

整个程序没有任何网络上报、不收集数据，运行起来几乎不占资源。
